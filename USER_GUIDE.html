eBay Price Wizard

Version 1.5.2-rc.1 · Independent CCTV variation pricing and SKU helper.

Release candidate. Calculations and input handling have automated local tests. Live eBay installation and editor compatibility have not been validated for this release. Review every generated value before saving.

Install

  1. Extract the extension ZIP into a permanent folder.
  2. Open chrome://extensions in Chrome and enable Developer mode.
  3. Choose Load unpacked and select the folder containing manifest.json.
  4. Reload the eBay listing page and open its variations table. There is no toolbar popup.

Calculate prices

  1. Click Wizard. Enter prices for the 4-, 8-, 16- or 32-channel recorders you sell; leave other channels blank.
  2. Enter the price of one camera.
  3. Select the HDD capacities used in the listing and verify or edit their prices. Detected capacities are selected from currently rendered rows only. Custom capacities require a price.
  4. Leave the promotional field blank, or enter a value from 0 to 83.33. Click Done.
  5. Click Preview. It checks the first ten currently rendered rows and shows calculated prices without writing them.
  6. Keep Only fill empty / zero prices enabled to preserve existing prices. Click Run when ready.
  7. Inspect all rows, including skipped rows, then use eBay's own save flow if satisfied.

base = recorder + HDD + cameras × camera price
final = base × 100 / (100 − promotional input × 1.2)

Synthetic example: £100 recorder + £50 HDD + four £20 cameras = £230. Promotional input 10 gives £230 ÷ 0.88 = £261.36. This is not a simple 12% markup or an eBay fee/tax calculator. Values near 83.33 produce very large results.

Build SKUs

Open SKU Wizard. Configure included columns, order, token mappings, patterns and separator. {v} means the mapped token; {n} means the first number in the option. Empty tokens omit an option.

Example: recorder token DVR-8CH, camera token CAM with pattern {n}x{v}, HDD token 2TB and separator + produce DVR-8CH+4xCAM+2TB.

Preview first, then Run. Only-empty is enabled by default. Camera rules can skip quantities above recorder capacity, limit to a list such as 0-2-4 (three allowed values, not a range), or omit zero-camera rows.

Save stores SKU settings in the current eBay origin's localStorage. Undo is limited to retained inputs from the last run; it cannot reliably undo recycled rows or a saved listing. Price filling has no Undo.

Storage and permissions

The script runs on matching HTTPS eBay UK and US pages and frames. It has no additional API permissions, background worker, analytics or explicit network requests. Price setup stays in page memory. Saved SKU configuration uses skuWizardCfg_v2 in site localStorage, accessible to other scripts on that origin. Do not store secrets there. eBay's own code can process changed inputs.

Limitations and troubleshooting

  • English CCTV table headers and editable inputs are required; not every editor is supported.
  • If the panel does not appear, reload after opening the editor. Grid detection polls for about 30 seconds.
  • If rows are skipped, check recorder prices, enabled HDDs, HDD costs and recognizable camera quantities.
  • Automatic scrolling is best effort on virtualized tables. Inspect all rows manually.
  • Do not run price and SKU filling together. Stop a run before changing setup.
